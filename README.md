# Bala Vardhan Portfolio

Personal portfolio for Bala Vardhan, a full-stack developer working across React, Next.js, Node.js, databases, and product workflows.

## Stack

- Next.js App Router
- React and TypeScript
- CSS tokens and responsive layout
- `lucide-react` icons

## Local development

```bash
npm install
npm run dev
```

Open `http://localhost:3000` to view the portfolio. Run `npm run lint` for code quality checks and `npm run build` for the production build.

## Routes

- `/` - portfolio homepage
- `/projects/vkart` - VKart project case study

## Content notes

Project and experience claims should stay aligned with the current resume, source repositories, and live demos. Add verified metrics and implementation details to the VKart case study as they become available. Do not publish credentials or private client information.
